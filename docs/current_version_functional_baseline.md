## 保护范围

本轮 Hermes 风格学习架构改造必须满足以下不变量：

1. `src/app/routes.ts` 的页面路由、`src/app/components/Layout.tsx` 的导航分组和顺序不变。
2. 现有页面组件、API 合约、权限边界、审计、自动化、报告、数据资产、知识记忆和系统配置功能不被删除或替换。
3. 已维护的数据资产、原始表、主题表、指标、Skill、自动化任务、报告版本、记忆和审计记录不做批量重写。
4. Smart Data Agent 继续从配置的 CSV 文件夹读取交付数据；定向爬取执行保持暂停，历史配置和记录保留。
5. 新能力只能作为后台增量层接入：用户操作事件 → 学习候选 → 四眼审核 → Skill 生效 → 后续分析应用 → 效果反馈。

## 当前业务功能与流程

### 智能分析

用户问题和页面上下文进入受治理分析流程，经意图识别、知识与已审核记忆装载、类型化分析计划、权限校验、语义查询、数据处理、可视化、智能结论和最终证据复核后形成分析任务。真实结论必须保留 SQL、数据快照、证据和审计链路。

### 经营周报与日报

周报支持版本保存、历史版本、评论、选区分析和结论生成；日报邮件以可发布报告版本为唯一证据来源，通过不可变产物和通知出站链路发送。

### 数据资产与治理

系统维护原始表、主题表、指标字典、意图、分析经验、行为习惯、知识文件、分析 Skill、外部工具和快捷分析配置。分析事实资产使用版本、审核、发布、血缘和质量门禁；运行配置类资产保持既有即时保存行为。

### Agent、Skill 与工具

系统已有 Agent Catalog、Agent Group 阶段门禁、Skill Config Catalog、Skill Registry、Skill Executor、MCP Gateway、权限审批和调用追踪。现有核心分析执行 Skill 为 `supersonic.query`；其他声明型能力未实现时必须明确显示为 `configured_unimplemented`，不得伪装为成功。

### 记忆与自动化

系统已有候选记忆、四眼审核、激活记忆检索、知识文件记忆提取、自动化任务、持久化运行、重试、取消、监控和通知能力。候选记忆不会在审核前进入分析上下文。

### CSV 数据源

Smart Data Agent 不再执行定向爬取。独立采集或文件交付服务将 CSV 写入 `SMART_DATA_AGENT_CSV_SOURCE_ROOT`；系统读取 CSV，并保留原始表、字段映射、历史产物和已暂停的爬虫任务作为审计历史。

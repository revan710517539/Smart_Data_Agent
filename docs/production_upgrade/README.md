# Smart Data Agent 生产化整改总览

本目录保留 114 项审查问题、实现证据和生产运行基线。目标是在保持现有页面样式和主要交互不变的前提下，把系统升级为可供约 100 人使用的可信数据分析、自动化汇报与经营运营平台。

## 基本原则

1. 页面不生成业务数字；没有证据的字段显示为空或不可用。
2. 一次分析只有一条事实链：计划、授权、执行 SQL、参数、数据快照、脚本、图表、结论、评审。
3. Mock、降级和真实执行严格区分；Mock 结果不得发布到正式报告。
4. 权限在查询执行前生效，所有业务对象执行租户、组织、所有者和数据范围校验。
5. 数据获取、分析、周报、经验、待办、通知通过稳定 ID 和领域事件串联。
6. SQLite 只保留为本地开发模式；生产使用 PostgreSQL、连接池、对象存储和异步 Worker。
7. 每项整改只有在实现、自动化测试和验收证据都存在时才可标记完成。

## 状态定义

- `待处理`：尚未开始。
- `整改中`：已有代码或设计变更，但尚未完成全部验收。
- `待验证`：实现完成，等待全量回归、迁移或浏览器验收。
- `已完成`：实现、测试、证据和文档均已闭环。

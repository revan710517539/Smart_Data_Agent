# SDA 统一可视化组件规范

版本：v1.0（2026-08-15）

## 1. 适用范围

本规范适用于 SDA 由分析任务动态生成的可视化卡片，包括智能分析当前结果与已保存报告。固定业务页面可以逐步接入，但不得因此改变原有数据口径、权限、路由或服务端分析逻辑。

唯一实现入口为 `AnalysisVisualCard`。新生成的图表不得另建一套工具条、追问抽屉或语音协议。

## 2. 视觉结构

- 表面：浅色背景、绿色主交互、冷灰文字和细边框；不参考 UI 标注稿的黑色画布底色。
- 线框：12px 圆角、1px 浅绿灰边框；弹层使用同色边框与轻量阴影。
- 标题区右上角固定三个小号文字操作：`显示数据 / 追问 / 操作`。
- `操作` 展开时，细长工具滑轨从按钮左侧展开，依次显示：`样式 / 指标 / 维度 / 实时语音`。
- 图表和表格继续使用系统已有字体、间距、空态和错误提示，不引入新的品牌色或图标体系。

## 3. 交互合同

### 显示数据

- 默认关闭；点击后变为 `隐藏数据`。
- 图形类组件把指标值绑定到柱、线、点、面积或扇区等实际图形元素上，不得在绘图区底部另堆一排独立标签；表格、交叉表与 KPI 不隐藏其固有内容。
- 再次点击恢复，不能改变数据源、查询结果或保存状态。

### 追问

- 有数据时可用，无数据时禁用。
- 点击后展开当前页面右侧统一栏并选中 `AI分析`，不打开右下角 Agent 总管。
- 锚点只传递任务/报告标识、可视化类型、指标名、行数、问题、总结、计划和已选数据表 ID；不得复制原始结果行。
- 当前图表锚点进入持久化分析 workspace；后续问题支持多轮、分支、合并和可信证据查看。
- 未选择图表而直接展开 AI 页签时，按当前页面整体分析。

### 操作滑轨

- 再次点击 `操作` 收起滑轨和所有二级面板。
- `样式` 使用系统现有可视化类型列表。
- `指标` 与 `维度` 面板展示当前结果可用字段；点击切换，第一项是当前主指标或主维度。
- 在字段芯片上按住鼠标右键 420ms 后进入浮起态；保持按压并横向或纵向移动可排序，松开结束。拖动后的视觉顺序必须同步更新，不得只修改内部状态；普通右键菜单被抑制。

### 实时语音

- 使用系统已配置的 Fun-ASR `realtime_voice_input` 模块和既有 WebSocket 代理，不新增浏览器或第三方语音旁路。
- 支持样式、主指标、主维度以及显示/隐藏数值命令，例如“改成折线图”“用放款金额做指标”“按日期作为维度”“显示数据”。
- 未配置、拒绝麦克风、网络断开或未识别命令时只显示局部提示，图表保持原状态。

### 评论

- 图表区域右键显示轻量 `评论` 操作；点击后展开统一右栏 `评论` 页签并生成与图表锚点绑定的草稿。
- 评论使用现有机构共享评论线程、乐观更新、回复与解决逻辑；不得写入分析线程。

## 4. 统一右栏

- 页签固定为 `评论 / AI分析 / 留言板`，每次进入页面默认折叠。
- 鼠标进入页面最右侧感应区后显示居中展开按钮；点击展开。
- 页面评论、AI 分析、留言板和图表追问动作均可直接展开并切换到对应页签。
- AI 分析宽栏为 640px；进入宽栏时自动收起左侧菜单。恢复为 320px 不强制恢复左侧菜单。
- 周报 AI 页签保留原有页面分析卡片，同时增加 `分析线程` 模式；两者共享同一报告 workspace，不覆盖历史轮次。
- 右下角 Agent 总管只保留通用对话和页面操作，不再重复承载分析线程。

## 5. 留言删除合同

- 用户留言卡片的关闭按钮语义为删除，不是完成或归档。
- 删除必须同时校验租户、作者和 `expected_lock_version`；成功后记录审计事件并从用户列表、管理员列表中消失。
- 跨用户删除返回 403，陈旧版本返回 409；失败时保留原卡片。
- 管理员仍可在管理页对未删除留言设置 `新增加 / 已采纳 / 已完成` 状态。

## 6. 可访问性与验收

- 所有按钮必须有稳定的中文可访问名称；禁用状态可被读屏和自动化测试识别。
- 工具滑轨、弹层、评论入口、右栏折叠/展开和宽栏状态必须暴露 `data-*` 合同供回归测试使用。
- 验收至少包括：类型检查、前端大小门、API 合同、留言删除权限/冲突测试、右栏契约、生产构建、已登录浏览器主流程、控制台错误和同状态视觉对比。

## 7. 回滚

回滚只撤回统一可视化组件、右栏接线、留言删除端点、聚焦测试和本规范。没有数据库迁移；已存在的评论、留言、workspace、thread、turn 和分析产物不做数据回滚。
